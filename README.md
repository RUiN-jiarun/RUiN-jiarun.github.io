# Jiarun Liu — Personal Homepage

A lightweight static academic homepage deployed with GitHub Pages.

## Structure

```text
.
├── index.html
├── sitemap.xml
└── assets
    ├── css           # Site styles
    ├── docs          # CV and downloadable documents
    ├── icons         # Favicon
    └── images
        ├── logos
        ├── profile
        ├── projects
        └── publications
```

## Local preview

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open <http://127.0.0.1:4173>.
